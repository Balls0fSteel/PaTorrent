## 2026-11-04_102209_1793784129: Version 1.1.58: "Use only this network", binding torrent traffic for VPNs (D54)

- **D54 (built by an Opus 5.5 agent, reviewed and merged):** Preferences > Connection > "Use only this network": a rule (any VPN adapter; an adapter by its GUID or device name; an address range such as 10.2.0.0/16) binds every socket carrying torrent traffic to the matched adapter's addresses: listening, uTP, DHT, LSD, outgoing peers, HTTP and UDP trackers, web seeds (`core::net::bind`, `engine::network_rule`, after libtorrent's `bind_outgoing_socket`). Re-evaluated on every network change; a v4-only tunnel turns IPv6 off; no port mapping is asked of a tunnel; a rule that cannot be parsed binds to nothing. Proxy connections, the Web UI and the remote protocol stay unbound. VPN detection: Windows IfType 23/53/131 or Wintun, TAP-Windows, WireGuard in the description; Unix `wg*`, `tun*`, `tap*`, `utun*`; point-to-point adapters.
- **"Pause torrents while this network is missing"** (on): while nothing matches, running torrents are held by the session and show "Waiting for the network", then resume by themselves; their own flags are untouched, so Stop and Start still work, and nothing is persisted. The Logger names the rule that found nothing. **"Your address as trackers see it"** in the General tab and the status bar's network tooltip. The engine sends its adapters to the frontends (`Alert::NetworkAdapters`; remote protocol 14, so a GUI and nox must both be current). Keys `net.network_rule`, `net.pause_when_missing`; nox `--network RULE`, `--[no-]pause-when-missing`. 14 strings in every table; three D55 help texts for the new controls written at the merge.
- **Checked:** the loopback engine tests (127.0.0.2 as the tunnel: the listen socket, a tracker announce, a peer connection and a DHT packet leave from it, an IPv6 peer is refused; the hold, the user's Stop and Start, pause off, rule off, the adapters on request) on Windows and Linux; clippy clean on both; the Win32 Preferences tests. Not run: a real VPN, any GUI, macOS, FreeBSD (BACKLOG "Network binding for VPNs").
