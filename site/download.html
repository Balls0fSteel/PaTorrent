Download PaTorrent

Every release is on the releases page on GitHub.

This is a pre-release. It has had little testing beyond its author's machines, settings may still change before 1.0, and it should not be used on private trackers yet. Its release notes list the known limitations.

Which file do I need?

  • Windows 10 or 11 The installer sets PaTorrent up and later upgrades it in place (from 1.0.1 on). The portable zip installs nothing: unzip it and run.
  • Linux desktop The AppImage carries its libraries and needs glibc 2.39 or newer (Ubuntu 24.04, Fedora 40, Debian 13 or later). Prefer Flatpak? Take the bundle. The plain binaries use your system's GTK 4 and OpenSSL 3.
  • Linux server The patorrent-nox AppImage, or patorrent-nox from the plain binaries, with its Web UI.
  • Mac Apple silicon: the disk image. Intel Macs get the headless patorrent-nox only, for now.

x64 and x86_64 are Intel and AMD processors; aarch64 and arm64 are 64-bit ARM.

Windows Your system

Windows 10 or 11, 64-bit (x64).

The file list is filled in when the site is built. Every file is on the releases page on GitHub.

SmartScreen

The programs are not code-signed, so the first time Windows SmartScreen shows “Windows protected your PC”. Choose More info, then Run anyway.

Settings and torrents go to %APPDATA%\PaTorrent. An empty patorrent.ini next to patorrent.exe keeps them in that folder instead (portable mode).

Linux Your system

x86_64 or aarch64.

The file list is filled in when the site is built. Every file is on the releases page on GitHub.

Good to know

  • Settings are in ~/.config/patorrent/gtk, torrents in ~/.local/share/patorrent/gtk. The Flatpak keeps them under ~/.var/app/io.github.balls0fsteel.PaTorrent/.
  • The Flatpak may write to your home folder, as a torrent client keeps writing to the folders you choose. A folder on another disk needs flatpak override --user --filesystem=/mnt/data io.github.balls0fsteel.PaTorrent (with your folder).
  • The daemon as a systemd service: docs/DAEMON.md.

macOS Your system

The GUI: Apple silicon, macOS 15 or newer. The daemon: Apple silicon (macOS 11 or newer) and Intel (macOS 10.14 or newer).

The file list is filled in when the site is built. Every file is on the releases page on GitHub.

Gatekeeper

PaTorrent.app is ad-hoc signed and not notarised, so Gatekeeper refuses it the first time (“cannot be opened because the developer cannot be verified”). Right-click (or Control-click) the app, choose Open, then Open again. Or remove the quarantine flag after copying it to Applications:

xattr -dr com.apple.quarantine /Applications/PaTorrent.app

The GUI is for Apple silicon only for now; on an Intel Mac, use patorrent-nox and its Web UI. Settings and torrents are in ~/Library/Application Support/PaTorrent/gtk.

Headless: patorrent-nox

The daemon is in the Windows zip, the Linux plain binaries, its own Linux AppImage and the macOS tarball. Start it with the Web UI on port 8080:

patorrent-nox run --webui 8080 --webui-pass PASS

Then open http://127.0.0.1:8080 on the same machine and log in as admin. Without --webui-pass it prints a temporary password at the first start; set one in Preferences > Web UI. The same port serves a qBittorrent-compatible Web API for existing tools.

From other machines: give an address, such as --webui 0.0.0.0:8443, and add --webui-https so the password does not travel in the clear (a self-signed certificate is made on first use). patorrent-nox add file.torrent --save DIR adds a torrent. Running it as a service (systemd, FreeBSD rc.d, a Windows service, --daemon) is in docs/DAEMON.md.

Checking a download

Each release on the releases page has a SHA256SUMS file.

With SHA256SUMS in the same folder as your download:

Linux

sha256sum -c --ignore-missing SHA256SUMS

macOS

shasum -a 256 PaTorrent-*.dmg

Compare the result with the file's line in SHA256SUMS.

Windows (PowerShell)

Get-FileHash .\patorrent-*.zip

Compare the hash with the file's line in SHA256SUMS (case does not matter).

Updating

PaTorrent does not update itself. From 1.0.1 on, the GUIs show a short note in their status bar when a newer release is out (from 1.1.17, patorrent-nox prints a line and shows a link in its Web UI); download that from this page or from GitHub. What changed is on the News page. The check reads one small file from this site and can be turned off (what it sends).

  • Installer: run the new installer. It upgrades the installed copy in place.
  • Portable zip: quit PaTorrent, then replace patorrent.exe and patorrent-nox.exe with the new ones by hand. Your settings stay where they are (in portable mode, leave the rest of that folder as it is).
  • AppImage: replace the old file with the new one.
  • Flatpak: install the new bundle over the old one with flatpak install --user --reinstall and its file name.
  • Plain binaries and the macOS tarball: unpack the new archive and use its programs.
  • macOS: drag the new PaTorrent.app to Applications and replace the old one.

Older versions and every pre-release are on the releases page. To build PaTorrent yourself, see Building in the README.
