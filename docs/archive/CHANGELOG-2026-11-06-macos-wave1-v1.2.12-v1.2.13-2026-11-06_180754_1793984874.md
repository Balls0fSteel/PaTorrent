## 2026-11-06_132853_1793968133: Version 1.2.13: the Mac GUI's macOS integration (slice G); wave 1 complete

- Quit and logout wait behind the D47 closing window (`applicationShouldTerminate:` → `NSTerminateLater`; power-off shows it at once; Quit ends open sheets first, which otherwise blocked it on the VM); close and minimize into the status item, `--minimized`, Dock reopen; the status item (left click toggles, right/Ctrl click its menu, the speeds as tooltip); opening `.torrent` files and magnet/http links, a second start of a profile handing them to the running copy over `NSDistributedNotificationCenter`; completion notifications; LaunchServices associations and the per-profile LaunchAgent (the plist code moved to `frontend::integration::mac`, GTK re-exports it); Auto Shutdown's countdown with Sleep and Shut Down as Apple events to loginwindow (Hibernate greyed); About, Third-Party Notices, the update offer. The process holds one App Nap activity: on the VM a hidden app's engine slowed until quits hung and transfers stalled. `legacy::take_over_gtk` renames the GTK bundle's `gtk` libraries to `mac` at the first start, rewriting paths in the ini files. New string `MacAssocKept` (LaunchServices cannot give a type back to "no default").
- Merged with C, D, F and E: G's three commands move from kinds 53-55 to 61-63; `app::state` checks the Files commands, then Auto Shutdown's, then the torrents'; `app::shutdown` returns the `Exit` for the closing window after storing the Preferences field and the layout.
- Checked by slice G on the VM (screen locked, scratch HOMEs): the GTK takeover with a profile and remote windows, an existing LaunchAgent read back, the quit flow (200 ms real, 16.6 s with `ROOKPARCEL_DEMO_SLOW_EXIT=12` behind the closing window), `open` of a file and a magnet with the app running and not, the second-start forward, `--minimized`, Dock reopen, About and Notices, the update offer, Auto Shutdown dry runs after a real download. `UNUserNotificationCenter` refuses the ad-hoc-signed app; the `NSUserNotificationCenter` fallback delivered. **Not checked:** close/minimize to tray, the status item's menu, Quit Now, writing the LaunchAgent and associations, the translocation notice, a real Sleep. **Issue:** an earlier run with 256 KiB pieces from a second profile connected but never downloaded (16 KiB pieces worked); not investigated (BACKLOG).
- Windows: clippy (both Apple targets, Windows incl. Win32 and nox), the GTK crate linted with a stand-in pkg-config for Linux and the Apple target, fmt, the Mac and frontend tests.

## 2026-11-06_130647_1793966807: Version 1.2.12: Mac Preferences with instant apply (slice E)

- One Preferences window with a sidebar of the pages (Disk Cache and Disk I/O under Advanced), each built from `pref_pages` in an `NSGridView`; changes apply at once with no OK or Apply (`pref_pages::live` keeps the bookkeeping, with tests): a bad value shows its message in red under the field and is not applied, a value refused only together with another waits for it, and closing the window puts back the applied text. The Advanced table edits in place; the Scheduler grid paints by drag. New string `MacPrefAdvancedNote` (the old note says "OK or Apply"), machine-translated into all tables.
- Merged with C, D and F: E's `Command::Pref` moves from kind 100 (slice C's) to 60; `ALL` holds both F's and E's commands. **Fixed at the merge:** a value still being typed was lost when quitting with Preferences open; `prefs::before_quit` commits it before `Core::shutdown`.
- Checked by slice E on the VM in English and German (a test tour driving the controls' own actions, since the locked screen hid the windows from accessibility): a check box and the port written to `rookparcel.ini` at once, a bad port refused under its field, a closed window keeping the good port, a Scheduler drag stored, the Advanced filter. **Not checked:** hover and focus help, real typing, the panels, Random port and Reload IP filter clicks; associations and autostart wait for slice G.
