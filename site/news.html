Fri 30 Oct 2026 — PaTorrent 1.1.17

Torrent search through your own Prowlarr or Jackett, in both GUIs and the Web UI. The Windows GUI's Web UI gains the RSS Downloader, and patorrent-nox now checks for updates too.

  • Search: Search for torrents through the Prowlarr or Jackett you already run (Torznab). PaTorrent has no search plugins or site scrapers of its own, so nothing breaks when a site changes.
  • Windows: The arrow beside the toolbar's search box picks a source or All sources; Enter opens Search Torrents, where results can be sorted and added.
  • GTK: The menu beside the search box does the same on Linux, BSD and macOS.
  • Web UI: A Find button beside the filter box opens the same search.
  • Search: Manage Sources adds, edits, tests and switches sources. API keys are stored encrypted on Windows. A source on this computer or your local network is reached directly; a public one goes through your proxy, if you set one.
  • RSS: The Windows GUI's Web UI has the RSS Downloader: it edits the window's own feeds and filters.
  • Security: For Sonarr, Radarr and Prowlarr: an optional API key and an optional list of subnets that need no login (Web UI Preferences > Authentication). Both are off by default and need the current password to change.
  • *arr: An add without a folder goes to its category's folder; in the Windows GUI's Web UI, unused categories survive a restart; tags are accepted and ignored, so the apps stop logging warnings.
  • Windows: Preferences > Web UI has a Server domains field, for apps that reach PaTorrent by a host name.
  • Daemon: patorrent-nox checks for a newer release like the GUIs: it prints a line and shows a link in the Web UI. --no-update-check or the Web UI's General > Privacy turns it off.

Settings and torrents from 1.1.x carry over unchanged.

Fri 30 Oct 2026 — PaTorrent 1.1.7

The Windows GUI serves a Web UI of its own, and PaTorrent works as a download client for Sonarr, Radarr and Prowlarr.

  • Web UI: Preferences > Web UI in the Windows GUI serves the same Web UI as patorrent-nox, over that window's torrents. It is off by default; the password is stored hashed, and HTTPS with a self-signed certificate is one tick.
  • Web UI: From the browser: add, start, stop, pause, label and remove torrents, and change the rate limits and most preferences. Changes show in the window within a second, and the other way round.
  • *arr: The seed ratio and seed time an indexer sends with a grab become that torrent's seeding goal.
  • *arr: The limits are reported back, so the apps' Remove Completed removes a torrent once PaTorrent has stopped it.
  • Fix: A refused host name now gets an error that says how to allow it: Preferences > Web UI > Server domains.
  • Fix: A seed without peers keeps counting its seeding time, so a time-based seeding goal stops it on time.
  • Windows: Opening a .torrent or magnet while PaTorrent runs brings its window forward (on by default). A torrent added stopped reads Stopped.
  • Security: patorrent-nox service install on Windows stores the Web UI login hashed, no longer on the service's command line, which every local user could read. --replace and --now make a changed setup one command.

1.1.2 was prepared but never published; its changes are in 1.1.7.

Wed 28 Oct 2026 — PaTorrent 1.1.0

A search box, importers from qBittorrent and µTorrent, and fixes across the engine, the Web UI and remote mode after a security review of the whole code base.

  • New: A search box in the toolbar filters the torrent list by name as you type; Ctrl+F jumps to it.
  • New: File > Import adds the torrents of qBittorrent (BT_backup) or µTorrent (resume.dat) with their save folders, labels and settings, and checks the files again. patorrent-nox run --import does the same.
  • Security: The DHT ignores replies it did not ask for, no peer connections go to ports below 1024, and feeds and redirects cannot reach your local network unless you added that address yourself.
  • Security: HTTPS needs TLS 1.2 and refuses revoked certificates. The Web UI limits connections before login, bans per client and asks for the current password before its security settings change.
  • Security: The GUIs connect to a patorrent-nox over HTTPS by default; plain HTTP to another computer needs your agreement first.
  • Fix: Windows: stopped torrents no longer show their last speed, rows no longer go blank after hovering or Select All, and the scheduler grid no longer flickers.
  • Windows: Alternating row shading, and Ctrl+S, Ctrl+T, Ctrl+Shift+P and Enter for Start, Stop, Pause and Properties.
  • New: Icons beside the category list, the detail tabs and the Preferences pages (Windows and GTK), and beside the Windows menu commands.

Update both sides for remote mode: the remote protocol changed, so a GUI and a patorrent-nox must both be 1.1.0 or newer to work together.

Tue 27 Oct 2026 — PaTorrent 1.0.1

The first stable release, with a Windows installer and an update check that only tells.

  • Windows: An installer beside the portable zip: for you alone or for all users, with a Start menu entry, .torrent and magnet associations, in-place upgrades and an uninstaller that keeps your settings unless you ask.
  • Updates: The GUIs read a small list of releases from this website at the start and every 12 hours, and show a newer version in the status bar. Nothing is downloaded or installed for you.
  • Updates: Help > Check for Updates asks at once; Preferences > General > Privacy turns the automatic check off. The Flatpak leaves updating to Flathub.
  • New: The version shows where µTorrent showed it: the window title, the tray tooltip, the Web UI's tab and the Windows files' properties.
  • New: Help > PaTorrent Website, and this website: downloads with how to start each file, the FAQ and the documentation.

There is no 1.0.0: its build stopped on a packaging check, and the version moved on. 1.0.0-rc.1 has no update check, so fetch 1.0.1 or newer by hand.

Mon 26 Oct 2026 — PaTorrent 1.0.0-rc.1

The first public build: a release candidate for 1.0, for people who want to try it and report what breaks.

  • New: The engine, our own Rust port of libtorrent-rasterbar 2.0.11: TCP and uTP, trackers, magnet links, DHT, peer exchange, encryption, web seeds, proxies, UPnP / NAT-PMP, IP filters, and BitTorrent v2 and hybrid torrents.
  • Windows: The µTorrent 2.2.1 main window with every column and detail tab, Preferences, the Add, Create and Properties dialogs, the RSS downloader, the scheduler and the tray icon. A portable zip, nothing to install.
  • GTK: The same main window and dialogs on GTK 4, for Linux, BSD and macOS.
  • Linux: An AppImage, a Flatpak bundle and plain binaries, for x86_64 and aarch64.
  • macOS: A disk image for Apple silicon; the headless daemon for Apple silicon and Intel.
  • Daemon: patorrent-nox runs headless with its own Web UI, HTTPS and a qBittorrent-compatible Web API subset, as a systemd, rc.d or Windows service.
  • New: English and 34 more languages, right-to-left layouts included; the translations are machine-made and unreviewed.
