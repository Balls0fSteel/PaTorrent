Command line

The everyday options. patorrent-nox --help lists all of them.

Command-line options
CommandWhat it does
patorrent-nox runStarts the daemon and resumes every saved torrent; q and Enter or Ctrl+C stop it cleanly.
patorrent-nox run --webui 8080 --webui-pass PASSThe same, with the Web UI and the qBittorrent-compatible Web API on 127.0.0.1:8080 (--webui ADDR:PORT for another address).
--webui-httpsServes the Web UI over HTTPS with a self-signed certificate made on first use; --webui-cert FILE --webui-key FILE uses yours.
patorrent-nox add file.torrent --save DIRDownloads a torrent into DIR and exits when it is done (--seed keeps seeding until stopped).
--no-update-checkStarts the daemon without its check for a newer release (1.1.17 and later; the Web UI's Preferences > General > Privacy does the same).
patorrent-nox run --verbosePrints tracker and peer events, useful in a bug report.
patorrent-nox --licensePrints the license and the third-party notices.
patorrent --remote, patorrent-gtk --remoteOpens a window that drives a patorrent-nox elsewhere (File > Connect to Remote... does the same).
patorrent --demo 10000Windows: opens the window on a simulated engine with 10,000 fake torrents, to try the interface at scale.
